00 — Executive Verdict

Don't buy DGX Spark Founders Edition. If you must, buy ASUS Ascent GX10.

The Spark is a specialist CUDA dev appliance, not a general-purpose internal LLM server. Its 273 GB/s bandwidth makes it 2–3× slower than a Mac Studio for interactive 70B chat, while its $4,699 price is ~$1,000 more than the identical ASUS GX10.

  • Don't buy for "host a 70B internal chatbot quickly." A Mac Studio M4 Ultra / M3 Ultra is faster, quieter, and cheaper to run for dense models.
  • Consider ONE unit only if you need a local CUDA replica of your DGX Cloud / H100 pipeline — to prototype agents, fine-tune with Blackwell kernels, and test ConnectX-7 RDMA before burning Inception credits.
  • If you buy GB10, buy ASUS Ascent GX10 — identical chip, memory, and software for ~$1,000 less. Dell Pro Max GB10 also fixes Spark's thermals and missing power LED but costs a bit more.
  • Practical ceiling is 70B dense (FP8/Q4) for interactive use. Nvidia's "200B" is NVFP4 / MoE-only with tiny active params. 405B barely fits and is unusable for chat.
  • Ollama on Spark is currently broken — use llama.cpp or vLLM, not Ollama Docker, or you will see "extremely slow" reports.
Price trap: Launched at $3,999 → now $4,699 MSRP since Oct 2025 due to LPDDR5X supply constraints. At this price, price/perf for pure LLM hosting is negative vs both Mac Studio and AMD Strix Halo 395.

01 — What DGX Spark Actually Is

A desktop Blackwell AI factory — not a mini-PC.

If you evaluate it as a fast office PC, you'll be disappointed. If you evaluate it as a portable Nvidia AI factory, it makes sense.

GB10 Grace Blackwell Superchip

Co-designed with MediaTek · ARM64
  • 20-core Arm: 10× Cortex-X925 + 10× A725
  • Blackwell GPU · 48 SMs · sm_121
  • Compute: 1 PFLOP @ FP4 (only)
  • Usable: 119.68 GB of 128GB

Memory & Storage

Unified — CPU and GPU share one pool
  • 128GB LPDDR5x unified
  • Bandwidth: 273 GB/s
  • 4TB NVMe SSD
  • No separate VRAM — good for MoE, bad for dense decode

Networking & IO

Built for clustering
  • ConnectX-7 · 200 GbE QSFP (1× port)
  • ~106 Gbps TCP · ~200 Gbps RDMA/Infiniband
  • Needs x4 PCIe Gen5 — can't do 400G
  • 280W (Dell) / 240W (Spark) PSU

Software & Support

The hidden cost
  • DGX OS — Ubuntu 24.04 based
  • Only 2 years guaranteed updates
  • CUDA on ARM64 — many libs need recompile
  • MLX not available · Blender no GPU on Arm
Nvidia's "200 billion parameters" claim: Requires NVFP4 (0.5 bytes/param) + MoE sparsity. For a standard dense model in BF16 it's 64B max. Don't budget 200B for your internal Llama 70B deployment.

03 — Real Performance: Why Reddit Says "Slow"

273 GB/s is the bottleneck. Prefill is great, decode is not.

Token generation is memory-bandwidth bound. Spark loses to Mac Studio on streaming, wins on prompt processing.

Georgi Gerganov (llama.cpp creator) on Spark: "MXFP4 GPT-OSS 20B → 3,600 tok/s prefill / 59 tok/s decode · GLM-4.5-Air → 817 / 18 tok/s" — proves Spark is excellent for small MoE, mediocre for large dense.
Nvidia Forum: "Very poor performance with Ollama on DGX Spark — looking for help" / "GDX Spark is extremely slow on a short LLM test" — Nvidia staff reply: use llama.cpp / vLLM, Ollama Docker image is not optimized for GB10.

  • MoE researchers (DeepSeek, Qwen MoE) — sparse activation hides bandwidth
  • Need 128GB unified + 200G RDMA clustering on desk

  • "I bought the $4,000 AI Supercomputer. Then I sold it." — Bay41 blog

  • Ollama Docker users: "catastrophic latency despite high GPU util"

If you do buy — operating rules

  • Buy ASUS Ascent GX10 (~$3,499), not Founder's Spark ($4,699). Same silicon, same DGX OS.
  • Use llama.cpp or vLLM with NVFP4 / Q4_K_M. Avoid Ollama Docker — install natively.
  • Keep contexts ≤8K for 70B, or KV will OOM. Use prefix caching in vLLM for agents.
  • Plan for 2-year support cliff — Nvidia's track record for consumer-dev boards is mixed. Budget replacement by 2028.
  • Don't fleet: 1 unit for prototyping. For company-wide hosting, add a Mac Studio or cloud, not a second Spark.
Bottom line for Sai / budget: DON'T BUY DGX Spark at $4,699 for general internal hosting. If Inception requires a Blackwell desktop presence, approve ONE ASUS GX10 ($3.5K) as a CUDA dev appliance. Redirect the remaining $1.2K+ to Inception GPU credits or a Mac Studio for actual hosting — it will deliver faster tokens today.
