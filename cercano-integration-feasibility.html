03 · Platform detail

Practifi

Best documented route so far, with a critical distinction: Practifi’s regular API and Salesforce’s Hosted MCP use different OAuth setup.

A. MCP and API

Verified Practifi describes Sentir MCP as available only within its Sentir product. Its page markets permissioned CRM context for AI tools, including relationships, history, notes, and next steps; it does not publish a public transport endpoint, exact tool list, API contract, or client onboarding steps.[2]

Verified Practifi’s public API reference identifies version 1.0, REST over Salesforce Lightning Platform, OAuth 2.0, and a Salesforce Connected App. It recommends a sandbox (preferably partial-copy when available) and points clients to Practifi Client Success for sandbox support. The public docs show financial-advice CRM resources and create/read/update/delete operations; scope access to the specific objects and fields required.[1]

Separate Salesforce option Salesforce Hosted MCP supports a read-only SObject server for standard and custom objects. Salesforce’s client guide says external MCP clients use an External Client App and OAuth; Connected Apps cannot be used for that MCP authentication flow. The SObject Reads server is explicitly read-only. Anthropic’s Oct. 27 advisor-plugin announcement also lists a Salesforce connector, but does not say it is Practifi-specific or enumerate Practifi package-object coverage. Confirm object visibility and workflow fit in Cercano’s org before treating it as a Practifi connection.[4][5][16]

Underlying Salesforce APIs Salesforce’s platform documentation includes Bulk API/Bulk API 2.0 in the REST/SOAP API allocation guidance; its Pub/Sub API documentation supports OAuth session-based authentication. These are underlying Salesforce capabilities, not proof that every Practifi workflow/object or event is exposed for Cercano. Confirm permissions, object/event coverage, and the org’s live quota with its admin. The allocation is license/edition/add-on based and org-aggregated—not a universal 1M calls/day figure.[20][23]

Cercano security configuration not verified No evidence reviewed confirms that Cercano licenses Salesforce Shield, has Platform Encryption enabled, or encrypts email fields. These are org/field-configuration facts; ask its Salesforce admin for a current configuration report rather than repeating them as established.

Third-party custom integration option Knit advertises an Integrations Agent that can generate custom Practifi integration code and shows example CRM actions. This is a third-party vendor offer, not an official Practifi MCP or proof of a maintained prebuilt connector; its page does not settle Cercano’s security, data-handling, or commercial approval.[19]

Commercial note

The public pricing page lists Naya at $135/user/month, tiered by firm size/configuration, and Sentir at $195/user/month launch pricing through Dec. 31, 2026, with firm access to Practifi MCP. These are vendor-published list prices, not Cercano’s signed terms or proof of the subscription it owns.[3]

Decision for the meeting

First establish whether Cercano uses Sentir or Naya. If Sentir is not in scope, ask for a least-privilege Practifi API sandbox and compare it with Salesforce Hosted MCP. Do not assume the two OAuth paths are interchangeable.

04 · Platform detail

Addepar

Strong public API documentation; access control and production authorization are the gates.

A. MCP and API

Official integration, rollout needs confirmation Anthropic’s Oct. 27, 2026 announcement lists Addepar as a connector in Claude for Financial Advisors, whose advisor plugin is described as available today. Addepar’s own MCP landing page still invites firms to a beta waitlist. These current official pages conflict on access status; the route is real, but Cercano’s availability must be confirmed with Addepar/Anthropic. Neither public page specifies the claimed 15-tool count or confirms read-only-only behavior.[10][16]

Verified The developer docs describe a REST API over HTTPS using JSON:API, with v1 portfolio, ownership, and admin resources. OAuth 2.0 authorization-code flow includes user approval and scoped access. The documented PORTFOLIO scope is read-only; other scopes may be read/write, and report generation currently has no read-only scope. Treat scope choice as a material risk control.[6][7]

The OAuth documentation says Addepar supplies the client ID, secret, and scope list; the integration provider supplies the redirect URI plus Terms and Privacy URLs; Cercano’s user authorizes access. Access tokens last 60 minutes and the authorization code expires after 60 seconds.[7]

Limits and access gate

Published firm-wide limits are 50 requests per 15-minute window, 1,000 in 24 hours, and a maximum 60-second request runtime. The docs describe a support path for requesting increases. Model any polling or batch workflow against these quotas and confirm them with Addepar before production.[8]

Addepar’s Developer Portal Terms say access is discretionary and limited to development/testing with non-production or dummy data; they do not grant production API rights. The terms prohibit reverse-engineering the Developer Portal/API. A separate API-specific agreement may control; Cercano’s production agreement must be reviewed before implementation.[9]

“does not grant you any right to use the API for production purposes.”Addepar Developer Portal Terms · Section 1, Developer Portal Access · excerpt under 15 words [9]

Decision for the meeting

Ask whether Cercano can use Addepar through Anthropic’s newly announced financial-advisor plugin; separately confirm whether Addepar’s MCP waitlist is a distinct route and whether the firm is eligible. Keep a vendor-approved OAuth API path as a fallback.

05 · Platform detail

MoneyGuidePro / Envestnet | MoneyGuide

A direct Claude MCP setup and a native Addepar account-import path are documented; the exact MCP data scope and Cercano entitlement remain unknown.

A. Public evidence and boundary

Official Claude MCP setup documented MoneyGuide’s integration catalog links a 2026 advisor guide that says to enable Has MCP in User Options → Partner Options → Contact Manager. The advisor then selects the “Envestnet MoneyGuide” connector in Claude, is redirected to MoneyGuide to authenticate, and reviews the Terms of Service. The guide does not enumerate MCP tools, data scope, or read/write permissions; Cercano’s entitlement still needs confirmation.[17]

Additional Claude route Anthropic’s Oct. 27 Claude for Financial Advisors announcement lists an Envestnet connector that summarizes Tamarac accounts and households with a financial-plan snapshot from MoneyGuide. Anthropic says its advisor plugin is available today and recommends Enterprise for RIAs because it includes audit logs; these are Anthropic’s published statements, not proof of Cercano’s license or compliance coverage.[16]

Native Addepar account import MoneyGuide’s official Addepar guide documents enabling the Addepar partner option, requesting Addepar authorization, then selecting an entity/group and mapping chosen accounts, owners, and account types into MoneyGuide. This confirms a selected-account import path into MoneyGuide—not bidirectional synchronization or the full demographics/holdings/plan-output scope claimed in the earlier summary.[18]

Direct API scope still gated/unclear Envestnet’s Developer Portal confirms a MoneyGuide API use case for displaying plan results on a client portal, but the pages reviewed do not establish a complete public API specification, authentication, rate limits, write scope, or the approval process. Do not state partner approval or a required Institution ID as confirmed without the current Envestnet integration pack; MoneyGuide’s catalog links to an Institution ID locator, but that alone does not prove this specific workflow requires it.[11][12]

Terms and security

MoneyGuide’s public Terms of Service include an “Other Prohibited Activities” section that restricts reverse engineering without prior written consent and restricts scraping/collection not expressly authorized by the company. Do not use browser automation or captured calls to bridge the documentation gap without written vendor approval and Cercano counsel/CCO sign-off.[13]

“without our prior written consent.”MoneyGuide Terms of Service · “Other Prohibited Activities” · excerpt under 15 words [13]

The security page makes vendor statements about security controls and annual SOC 2 Type II audits for its data centers; it also states support for TLS 1.1 and TLS 1.2 or later. The page is not a current independent attestation. Request the latest SOC 2 report, scope, exceptions, subprocessor list, encryption details, and incident-response terms through Cercano’s vendor-diligence process.[14]

Decision for the meeting

Request a current API/integration pack from Cercano’s Envestnet contact, including permissions, allowed data use, technical onboarding, pricing, sandbox, and production approval. Keep this route “unresolved” until those are answered.

06 · Nonstandard access

Browser-capture and reverse-API tools

A generated client is not the same as an approved integration. For these systems, technical possibility is not permission.

What a traffic-capture tool can do

A tool in this category may observe requests made by an authenticated browser and draft a client wrapper. It cannot make private endpoints stable, grant production rights, or prove the resulting client is safe. No such tool was tested against Cercano’s Practifi, Addepar, or MoneyGuide tenant in this review.

What it cannot establish

It cannot establish contractual authorization, vendor support, complete data coverage, or security review. SSO/MFA, rotating sessions, CSRF protections, UI changes, and endpoint changes are plausible failure modes; these are technical risks, not target-platform test results.

08 · Recommended path

Integration sequence

Keep the first proof of concept narrow, reversible, and auditable.

Confirm entitlement

Have Cercano identify plan, product, admin owner, and existing vendor approvals.

Use official access

Evaluate the Anthropic financial-advisor connectors and MoneyGuide’s direct Claude MCP setup, subject to firm licensing/entitlement. Otherwise use Practifi/Addepar vendor APIs or Salesforce read-only MCP with approved scopes.

Test read-only

Use a vendor-approved sandbox or synthetic data and minimum data fields. Validate identity matching and data freshness.

Govern before writes

Require CCO/IT approval, audit logging, retention controls, secret management, and human approval before any record change or client communication.

Compliance boundary: SEC/FINRA recordkeeping and Regulation S-P requirements were not independently researched against primary legal sources in this report. Cercano’s CCO/counsel must determine which rules apply to each regulated entity and define retention, privacy, vendor-diligence, and human-review controls before real client data is used.

09 · Client meeting

Eight prioritized questions for Cercano

  1. Which Practifi product and Salesforce edition do you run—Sentir, Naya, or another configuration—and who administers the org?
  2. Is Practifi Sentir MCP included and enabled? If not, can your admin provide a read-only Practifi API sandbox and manage a Connected App?
  3. Would you consider Salesforce Hosted MCP for read-only CRM queries, and which approved AI client is allowed to connect through an External Client App? Anthropic’s new advisor plugin also lists Salesforce—has your firm enabled that connector?
  4. What Addepar API/OAuth permissions and firm-wide quotas are available today? Can your Addepar contact sponsor a development environment and read-only scopes?
  5. Can your firm access Addepar through Anthropic’s newly announced financial-advisor plugin? Separately, is it enrolled in Addepar’s MCP beta, and what are the tool scopes and contract conditions?
  6. Is MoneyGuide’s “Has MCP” option enabled, and can your users connect the Envestnet MoneyGuide Claude connector? Which Anthropic/Envestnet licenses and data permissions apply? For broader APIs, ask the vendor for the current technical pack and sandbox path.
  7. Which platform is the source of truth for household identity, assets, and goals? What integrations already move these data, and in which direction? Can your Salesforce admin confirm whether Shield/Platform Encryption is licensed and enabled for email fields?
  8. Which regulated entity and CCO/IT review process will own vendor approval, data retention, audit logs, AI-provider controls, and approval of write actions?
