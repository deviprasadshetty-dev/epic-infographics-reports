05 — Defects & Remediation

Flaws Uncovered During Testing

Two critical logic vulnerabilities were isolated and resolved before production deployment.

Defect 1: Discontinued Client Leakage (Sunita Rao TC-10)

Symptom: Discontinued client Sunita Rao was selected and painted RED as an overdue task.
Root Cause: Step 1's Python script checked only Column 3 (Data Update Status = Updated) and ignored Column 4 (Member Category = Discontinued) and Column 5 (Service Category = Discontinued).
Fix: Enforce multi-column checking in Step 1 prompt: "Check Data Update Status, Member Category, and Service Category. If any contains 'discontinued' or 'inactive', skip the row."

Defect 2: Intermittent Meeting Search Skip (Boolean Gate Bug)

Symptom: Step 3 occasionally reported 0 meetings searched despite pending meeting stages.
Root Cause: Step 1 generated evidence_source_required: False instead of mapping meeting stages to ["meetings"]. Because Step 3 requires this flag, it skipped queries entirely.
Fix: Explicitly mandate in Step 1: "Map draft_fp_meeting and final_fp_meeting to evidence_source_required = ['meetings']."
