The one-paragraph version

Should you care?

Yes, if you run AI coding agents. This model does everyday agent coding jobs as well as models costing 17–40x more, and it does them fast. No, if you need it to work alone for hours, handle security, or answer hard science questions — the expensive models still win those by a lot. Use this one for the bulk work, keep a top model for the hardest 5%.

One caution: most "it beats Opus!" numbers come from DeepSeek's own testing, and the wins are tiny (under 5 points). An independent lab confirms it is strong (score 40) but hasn't re-run each head-to-head yet.

Money

What it costs, in plain words

You pay per million "tokens" (roughly word-pieces). There are two prices: normal hours and quiet hours (half price). Reading back something already in memory ("cache hit") costs almost nothing — that matters because coding agents re-read their work constantly.

A real example: one coding session that reads 2M tokens and writes 200K costs $0.42 in quiet hours on Flash vs $1.72 on the old Pro. Same work, quarter of the price. Rivals (Opus at $5/$25, GPT-5.6 at ~$4–5/$20–30) would charge roughly 17–40x more.

Fine print

5 catches, plainly stated

1

It talks too much. An independent lab found it writes nearly 2x more words than average to finish tests. Since you pay for written words, this eats into the savings on thinking-heavy jobs.

2

"Flash" doesn't mean small. The full model is ~550 billion parameters (~175–220 GB even compressed). You cannot run it on a laptop; even owners of special AI hardware struggle. For most people, use the API.

3

Top scores need the most expensive setting. Every headline number uses reasoning effort 100/100. Turn the dial down to save money and accuracy drops too.

4

Young model, rough edges. Users report occasional infinite loops, broken tool calls, answers slipping into Chinese, and one billing confusion where Pro users expected Flash prices. It is 2 days old — expect patches.

5

Check your bill. DeepSeek first said old Pro requests would auto-switch to cheap Flash prices on Sept 14, then quietly kept Pro running as-is. Don't assume — check which model id you're billed for.

Translator

Jargon buster

Mixture-of-Experts (552B total, 8–16B "active")
Think of a hospital with 552 specialists on staff, but only 8–16 walk into your room per question. Total size is huge; cost per question stays small.
KV cache (890 bytes per token)
The model's short-term memory of what it already read. Smaller memory per word = cheaper re-reading, which is most of an agent's bill.
Reasoning effort 1–100
A dial: higher = the model thinks longer and scores better, but costs more. All records above use 100.
Terminal-Bench / DeepSWE
Exams where the AI does real computer jobs (terminal commands, fixing GitHub bugs) instead of multiple-choice quizzes.
Tokens
Word-pieces the price is counted in. ~750 words ≈ 1,000 tokens.
Vendor-reported
Tested by the company selling the model — worth knowing, worth double-checking.
