02 — Cloud Account Reset & Recovery

Expired AWS & Google Cloud Credits: Exact Recovery Protocol

If you previously held AWS Activate or Google Cloud credits that expired, automated systems will flag repeat applications unless you follow the official escalation policy or execute entity isolation.

AWS Activate: The Escalation & Delta Route

Official Policy

The Rules of Reapplication

  • The Delta Grant Rule: If your expired credits were the $1,000 Founders Tier or a smaller tier, AWS explicitly allows applying for the Portfolio Tier ($10,000 to $25,000) as long as you haven't exceeded the $100,000 lifetime cap. AWS grants the incremental difference (e.g., $1k → $25k) if via Inception Org ID and lifetime <$100k.
  • Provider Affiliation: You must apply using an active Activate Provider Organization ID (e.g. from your free NVIDIA Inception membership).
  • Support Route: If locked out in the portal, contact aws-activate-support@amazon.com citing: "Requesting upgrade to Activate Portfolio tier via NVIDIA Inception Org ID following expiration of initial self-funded credits."

Alternative: Fresh Slate Creation

If the old account exhausted its lifetime cap or is blacklisted:

  • Create a new AWS account under your dedicated project domain (e.g. admin@sarvax.ai).
  • Attach a distinct credit card and different phone number (AWS fraud filters link accounts across identical billing cards).
  • Run nominal usage ($0.50) for 48 hours before submitting the Activate Portfolio application with your Inception Org ID.

Google Cloud: The Scale Tier & Entity Isolation

Official Policy

The Rules of Reapplication

  • The Scale Tier Upgrade: If you previously used the $2,000 Start Tier, Google allows applying for the AI-First Scale Tier (up to $100,000–$250,000) if you have an active accelerator affiliation (such as NVIDIA Inception).
  • Direct Outreach: Reach out to the regional Google Cloud Startups team: cloud-startups-support@google.com or connect with the India startup leads on LinkedIn.

Alternative: The Clean Entity Blueprint

Google evaluates 4 items: domain, Workspace tenant, billing account, and founder LinkedIn:

  • Deploy on a segregated domain (e.g. sarvax.ai) with its own Google Workspace tenant.
  • Link a fresh GCP billing account using a distinct corporate card.
  • Submit via the Google for Startups Cloud Program using your NVIDIA Inception affiliation.

04 — Field-Tested Approval Playbook

The 10-Point Underwriter Verification Checklist

Startup credit underwriters use automated scrapers before human review. Reddit post-mortems confirm these ten non-negotiable requirements to guarantee 100% approval on the first attempt.

1. Active DNS MX Records

Underwriters query WHOIS and MX records. Domains without MX records are flagged as disposable shells. Apply only with emails resolving to live MX records.

2. Zero-Gmail Policy

Never apply using @gmail.com, @outlook.com, or forwarder aliases. Both the applicant and cloud root account must use founder@yourdomain.com.

3. Live Production Website

Scrapers crawl your site. No "Coming Soon" or template Latin text. Must include an SSL certificate (HTTPS), pricing/demo, and clear product architecture.

4. Mandatory Legal Footers

Working links to Privacy Policy and Terms of Service in the footer are required by Microsoft and AWS automated compliance bots.

5. Founder LinkedIn Matching

Profile must be >60 days old with 50+ connections and list your startup as current employment (e.g. Founder & CEO at SarvaX.ai).

6. Anti-VPN Enforcement

Never apply over a VPN, proxy, or datacenter subnet. Microsoft and AWS score IP risk heavily; submit from a clean residential connection.

7. Geo-Consistency

Your IP location, credit card issuing country, and account billing address must align to prevent automated fraud triggers.

8. Payment Card Verification

Attach a valid international credit or debit card with Address Verification System (AVS) enabled. Avoid virtual single-use or prepaid cards.

9. 48-Hour AWS Account Burn-In

Never apply on a brand-new 10-minute-old AWS account. Create the account 48–72 hours prior and incur $0.50 of verified usage (S3/Lambda) first.

10. NVIDIA Inception Leverage

Retrieve your free Inception Partner Org ID from the NVIDIA portal to bypass the $1,000 self-funded limit for AWS Activate Portfolio ($10k–$25k).
